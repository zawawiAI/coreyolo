Designed for Apple silicon.

Fused convolutions. ReLU by default. A static square graph. The Neural Engine is the product path, not an afterthought.

Core ML first

Export an FP16 ML Program for iOS 16 and macOS 13. GPU, Neural Engine, or both — first-class compute units.

MIT

CoreYOLO’s code is permissive. Closed App Store apps can ship models you train here from scratch. Converted YOLOv9 weights stay AGPL-3.0 — that is not a relicensing.

Your labels

Drop in a Roboflow YOLO or YOLO-Seg export. Same data.yaml you already have.

From notebook to iPhone.

One SDK. Train, validate, predict, export. Application code loads CoreYOLO files only.

pip install coreyolo 
from coreyolo import YOLO

model = YOLO("n")                 # YOLOv9 GELAN; pass family="e2e" for NMS-free
model.train(data="data.yaml", epochs=100, imgsz=640)
model.save("weights/app.coreyolo")
model.export(imgsz=640)   # Core ML for iPhone

Tasks that ship.

Detection and instance segmentation today. Pose and OBB stay out of scope on purpose.

Detect

Anchor-free boxes at strides 8, 16, and 32. Class-aware NMS on the host for GELAN. Top-300 for E2E.

Segment

Proto masks on P3, Roboflow YOLO-Seg polygons, three Core ML outputs. Assemble masks after NMS.
