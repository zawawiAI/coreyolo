Designed for Apple silicon.

Inference-only export. Static DFL grids. ReLU by default. Palettized Core ML. The Neural Engine is the product path, not an afterthought.

Core ML first

Fused Conv–BN, inference branch only, cached DFL grids (no meshgrid / arange), host NMS. FP16 ML Program with 8-bit palettes. ReLU converts for the Neural Engine. iOS 16 and macOS 13.

From notebook to iPhone.

One SDK. Train, validate, predict, export. Application code loads CoreYOLO files only. Prefer Detector; YOLO is a compatibility alias.

pip install coreyolo 
from coreyolo import Detector

model = Detector("n")              # GELAN n; also "s" / "m" / "l", or family="e2e"
model.train(data="data.yaml", epochs=100, imgsz=640)
model.save("weights/app.coreyolo")
model.export(imgsz=640)   # Core ML: FP16 + 8-bit palette, ANE for ReLU

Three graphs. One trainer.

Pick the graph that matches the phone, not a 50-task zoo.

GELAN — default

GELAN as in the YOLOv9 paper. Scales n / s / m / l match public v9-t / s / m / c. Export is the main branch only (no PGI aux). Train ReLU here for ANE; optional convert stays SiLU (GPU) and MIT when the source is MultimediaTechLab.

n, s, m, and l.

Same GELAN trainer. Pick the scale for the device. Converted COCO weights for all four are in the zoo.

n — 2.13M

Phones, real-time camera. Matches public v9-t. Train with Detector("n") or convert v9-t.pt.

s — 7.32M

Mac and iPad. Convert v9-s.pt, or train ReLU with --recipe coco-s.

m — 20.22M

Accuracy-biased. Convert v9-m.pt, or train ReLU with --recipe coco-m.

l — 25.59M

Offline / max accuracy. Convert v9-c.pt, or train ReLU with --recipe coco-l.

Tasks that ship.

Detect

Anchor-free boxes at strides 8, 16, and 32. Class-aware NMS on the host for GELAN. Top-300 for E2E.

Segment

Proto masks on P3, Roboflow YOLO-Seg polygons, three Core ML outputs. Assemble masks after NMS.
