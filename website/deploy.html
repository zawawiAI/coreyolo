Deploy

A package you drop into Xcode.

Training is PyTorch on a Mac. The phone runs Core ML. There is no Python on iOS.

Export

Fused Conv–BN, cached anchors, FP16 ML Program, 8-bit palettize, iOS 16 / macOS 13. ReLU converts for ANE. Optional INT8.

Letterbox

The camera frame is padded to imgsz with gray 114. Same pad and ratio as training. Then boxes map back.

Host decode

DFL: class-aware NMS in Swift. E2E: top-300, no NMS. Segmentation: three tensors, assemble after NMS.

Export

One command writes the artifact the iPhone loads.

coreyolo export --weights weights/app.coreyolo --imgsz 640
# default: FP16 + 8-bit palettes, ANE-legal ops for ReLU
# coreyolo export --weights weights/app.coreyolo --imgsz 640 --no-palette
# coreyolo export --weights weights/app.coreyolo --imgsz 640 --int8
model.export(imgsz=640)

Export fuses Conv–BN, caches DFL anchors, converts as FP16, then palettizes weights to 8-bit k-means. ReLU-family graphs convert with CPU_AND_NE. Skip palettes with --no-palette; use --int8 for linear quant instead.

Swift

Use MLModel directly. This graph is raw tensors, not Vision VNRecognizedObjectObservation.

let config = MLModelConfiguration()
config.computeUnits = .cpuAndNeuralEngine   // ReLU; .cpuAndGPU for converted SiLU
let model = try MLModel(contentsOf: url, configuration: config)

A camera sample lives in examples/ios: letterbox, host NMS, iOS 16+. It defaults to Neural Engine. Drag CoreYOLO.mlpackage into the Xcode target, set a signing team, run on a device.

Compute units

Match the flag to the activation. ReLU, ReLU6, StarReLU, and HardSwish belong on the Neural Engine. Converted YOLOv9 weights are SiLU — prefer GPU for those, or train ReLU from scratch for ANE.

Flag Core ML Use
auto CPU_AND_NE, then GPU Core ML load: Neural Engine first. Use this for ReLU packages.
gpu CPU_AND_GPU CLI default. PyTorch MPS, or converted SiLU Core ML on GPU.
ane CPU_AND_NE ReLU / StarReLU fused graphs. iOS sample default.
all ALL Let the OS split GPU and ANE.
cpu CPU_ONLY Debug.
