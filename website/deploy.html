Deploy

A package you drop into Xcode.

Training is PyTorch on a Mac. The phone runs Core ML. There is no Python on iOS.

Export

Fused Conv–BN, cached anchors, FP16 ML Program, iOS 16 / macOS 13. Optional INT8 weight quant.

Letterbox

The camera frame is padded to imgsz with gray 114. Same pad and ratio as training. Then boxes map back.

Host decode

DFL: class-aware NMS in Swift. E2E: top-300, no NMS. Segmentation: three tensors, assemble after NMS.

Export

One command writes the artifact the iPhone loads.

coreyolo export --weights weights/app.coreyolo --imgsz 640
# or
model.export(imgsz=640)

Swift

Use MLModel directly. This graph is raw tensors, not Vision VNRecognizedObjectObservation.

let config = MLModelConfiguration()
config.computeUnits = .cpuAndGPU
let model = try MLModel(contentsOf: url, configuration: config)

A camera sample lives in examples/ios: letterbox, host NMS, iOS 16+. Drag CoreYOLO.mlpackage into the Xcode target, set a signing team, run on a device.

Compute units

Match the flag to the activation. ReLU graphs belong on the Neural Engine. Converted YOLOv8 weights are SiLU — prefer GPU, or fine-tune ReLU.

Flag Core ML Use
gpu CPU_AND_GPU Default. Converted SiLU weights.
ane CPU_AND_NE ReLU-fused graphs.
all ALL Let the OS split GPU and ANE.
cpu CPU_ONLY Debug.
