Models

A scale for every device.

Nano for phones. Small for Mac and iPad. Larger when accuracy leads and the model can wait.

Compound scaling

DFL follows the usual n / s / m / l / x ladder. E2E uses depth 0.50 on n / s / m.

Scale DFL depth / width Nano params (detect, nc=80) Typical use
n 0.33 / 0.25 3.16M (DFL) · 2.73M (E2E) iPhone, real-time camera
s 0.33 / 0.50 — Mac / iPad
m 0.67 / 0.75 — Accuracy-biased
l / x 1.00 / 1.00–1.25 — Offline / max accuracy

Graphs

Same trainer. Different graphs. Choose at train time with --family dfl or --family e2e.

DFL — default

C2f, SPPF, PAN-FPN, decoupled DFL head, reg_max=16. Eval is decoded xywh plus class scores. NMS on the host. Core ML layout (1, 4+nc, N).

Optional one-time tensor remap from YOLOv8n / YOLOv8n-seg into a native .coreyolo file. YOLO11n and YOLO26n cannot map.

E2E

Original C3k2, residual SPPF, C2PSA, dual TAL head, reg_max=1. Eval is NMS-free top-300, (B, 300, 6) as xyxy, conf, cls. Train from scratch.

Zoo

Binaries live on GitHub Releases, not in git. mAP stays blank until you record COCO val.
