Models

A scale for every device.

Nano for phones. Small for Mac and iPad. Larger when accuracy leads and the model can wait.

Compound scaling

GELAN (default) uses a fixed channel table; n / s / m / l match v9-t / s / m / c. DFL follows the usual n / s / m / l / x ladder. E2E uses depth 0.50 on n / s / m.

Scale DFL depth / width Params (detect, nc=80) Typical use
n 0.33 / 0.25 2.13M (GELAN) · 3.16M (DFL) · 2.73M (E2E) iPhone, real-time camera
s 0.33 / 0.50 7.32M (GELAN) · 11.17M (DFL) · 10.65M (E2E) Mac / iPad
m 0.67 / 0.75 20.22M (GELAN) · 25.90M (DFL) · 22.63M (E2E) Accuracy-biased
l / x 1.00 / 1.00–1.25 25.59M (GELAN-l) · 43.69M (DFL-l) · 27.17M (E2E-l) Offline / max accuracy

Graphs

Same trainer. Different graphs. Default is --family gelan (YOLOv9). Also dfl or e2e.

GELAN — default

ELAN1, RepNCSPELAN4, SPPELAN, AConv, DFL head. Scales n / s / m / l match public v9-t / s / m / c. Export is inference-only (no PGI aux). Train ReLU for ANE; remap stays SiLU.

DFL

Older C2f, SPPF, PAN-FPN, decoupled DFL head, reg_max=16. Eval is decoded xywh plus class scores. NMS on the host. Core ML layout (1, 4+nc, N).

E2E

Original C3k2, residual SPPF, C2PSA, dual TAL head, reg_max=1. Eval is NMS-free top-300, (B, 300, 6) as xyxy, conf, cls. Export drops the one-to-many train head. Train from scratch.

Zoo

Binaries live on GitHub Releases, not in git. mAP stays blank until you record COCO val.

Converted zoo rows (n-coco, s-coco, m-coco, l-coco): code MIT, weights MIT. Remap MultimediaTechLab v9-*.pt, copyright Kin-Yiu Wong and Hao-Tang Tsui. Keep that notice. They keep SiLU (GPU). Train recipes are original MIT weights (ReLU, Neural Engine). Ultralytics yolov9*.pt is a different dump (AGPL-3.0); converting the file does not change its applicable terms.
