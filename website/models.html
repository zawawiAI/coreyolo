Models

A scale for every device.

Nano for phones. Small for Mac and iPad. Larger when accuracy leads and the model can wait.

Compound scaling

GELAN (default) uses a fixed channel table; n matches yolov9t. DFL follows the usual n / s / m / l / x ladder. E2E uses depth 0.50 on n / s / m.

Scale DFL depth / width Nano params (detect, nc=80) Typical use
n 0.33 / 0.25 2.13M (GELAN) · 3.16M (DFL) · 2.73M (E2E) iPhone, real-time camera
s 0.33 / 0.50 — Mac / iPad
m 0.67 / 0.75 — Accuracy-biased
l / x 1.00 / 1.00–1.25 — Offline / max accuracy

Graphs

Same trainer. Different graphs. Default is --family gelan (YOLOv9). Also dfl or e2e.

GELAN — default

ELAN1, RepNCSPELAN4, SPPELAN, AConv, DFL head. Scale n matches Ultralytics yolov9t (no official yolov9n.yaml). Train ReLU for ANE; remap from yolov9t.pt stays SiLU.

DFL

Older C2f, SPPF, PAN-FPN, decoupled DFL head, reg_max=16. Eval is decoded xywh plus class scores. NMS on the host. Core ML layout (1, 4+nc, N).

E2E

Original C3k2, residual SPPF, C2PSA, dual TAL head, reg_max=1. Eval is NMS-free top-300, (B, 300, 6) as xyxy, conf, cls. Train from scratch.

Zoo

Binaries live on GitHub Releases, not in git. mAP stays blank until you record COCO val.

Converted zoo rows (n-coco, l-coco) remap Ultralytics YOLOv9 tensors. Those weights stay AGPL-3.0 and keep SiLU — export them for GPU, not ANE. Train recipes (relu / e2e / segment) are the MIT + Neural Engine path. See docs/licenses.md.

Id Graph Task Act Compute How Weights
coreyolo-n-coco gelan detect SiLU GPU coreyolo convert --weights yolov9t.pt YOLOv9 (AGPL-3.0)
coreyolo-l-coco gelan detect SiLU GPU coreyolo convert --weights yolov9c.pt YOLOv9 (AGPL-3.0)
coreyolo-n-coco-seg gelan segment ReLU ANE coreyolo train --task segment --family gelan MIT
coreyolo-n-coco-relu gelan detect ReLU ANE coreyolo train --recipe coco-n MIT
coreyolo-e2e-n-coco e2e detect ReLU ANE coreyolo train --recipe coco-n-e2e MIT

See weights/manifest.json in the repository.
